# PCG STATLAB — Cloud Edition

Statistics learning website with interactive lessons, calculators, quizzes and student progress sync.

## Architecture
- Static frontend in `public/`
- Vercel serverless API in `api/`
- MongoDB Atlas for progress storage
- Clerk for authenticated per-student sync

## Setup
See `START_HERE_SINHALA.md` for the beginner deployment instructions once the full source is uploaded.

**Deployment is not complete.** Do not configure Vercel until all frontend and backend source files are present. Never commit real `.env` secrets.
